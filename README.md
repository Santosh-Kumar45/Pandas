# Pandas Data Analysis

A collection of Python scripts and Jupyter notebooks for data analysis using the pandas library.

## What's inside
- Data loading (CSV, Excel, JSON)
- Data cleaning (missing values, duplicates, data types)
- Filtering, sorting, and grouping data
- Merging and joining DataFrames
- Basic visualization with Matplotlib

## Tech Stack
Python, pandas, NumPy, Matplotlib, Jupyter Notebook

## How to run
1. Clone the repo: `git clone <repo-url>`
2. Install dependencies: `pip install pandas numpy matplotlib`
3. Open the notebook: `jupyter notebook`
